These are coding activities prepared for kids and teens during my time at York.
You can find my laborious and thorough Class Planning for those lessons too.

## Contents

The lessons are of 30 minutes, and they have 1 lesson per week, across the span of 3 months total.
This is what I'm aiming for them to learn in those 3 months:

--- Scratch:
- All the instructions.
- Sync and async code inside each object.
- Sync and async code across multiple objects.
- Sprites, backdrops.

We will not get to learn more advanced topics such as Event Handling in depth.

--- Python:
- Why do we program / what is programming / etc.
- Variables
- Operators
- Datatypes
- Data Structures
- Control Flow Structures (branching) and Control Flow Graphs
- Functions
- Modules
